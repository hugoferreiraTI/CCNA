============================ VPN CONFIG ========================

[ FASE 1 - ISAKMP (Negociação e Canal Seguro) ]
crypto isakmp policy 1
 encr 3des
 hash md5
 authentication pre-share
 group 2

! Chave compartilhada:
! No R_CORE : crypto isakmp key cisco address 4.4.4.2
! No R2_NY  : crypto isakmp key cisco address 100.10.0.1


[ FASE 2 - IPsec (Criptografia dos Dados / Transform-Set) ]
crypto ipsec transform-set TS esp-3des esp-md5-hmac


[ CRYPTO MAP & ATIVAÇÃO ]
crypto map CMAP 10 ipsec-isakmp 
 set peer <IP_DO_ROUTER_OPOSITOR>
 set transform-set TS 
 match address VPN

! Aplicação na interface pública (WAN/Outside):
interface GigabitEthernet0/0/2 (ou porta de saída)
 crypto map CMAP
