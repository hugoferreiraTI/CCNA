In this lab, I implemented a fully configured network topology. The router was configured with a custom hostname, secure SSH access across all devices, and a Class C IP scheme (192.168.1.0/24).

I also segmented the network into two distinct VLANs—VLAN 10 and VLAN 20. These are interconnected through a Core Switch, which manages the VLAN database and trunking for the entire infrastructure.

To ensure disaster recovery and configuration management, all network equipment is backed up to a central TFTP server.
