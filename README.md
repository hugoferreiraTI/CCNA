CCNA-3001 - Estudos e Laboratórios

Este repositório foi criado para documentar minha evolução na trilha CCNAv7. A ideia aqui é centralizar todos os laboratórios práticos feitos no Cisco Packet Tracer, mantendo um registro organizado das topologias e das configurações de CLI (Cisco IOS) que desenvolvo ao longo dos módulos.

O objetivo principal é ter um material de consulta rápida para comandos e protocolos, além de servir como um portfólio técnico que demonstra a aplicação prática de conceitos como segmentação de redes (VLANs), roteamento, segurança de infraestrutura e automação.

Tudo o que está aqui reflete o que estou aprendendo nos três módulos do curso:

    Módulo 1: Introdução a Redes (ITN)

    Módulo 2: Switching, Roteamento e Wireless (SRWE)

    Módulo 3: Redes Corporativas, Segurança e Automação (ENSA)
